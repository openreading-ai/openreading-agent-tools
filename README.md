# OpenReading GitHub distribution

Install through your host's GitHub marketplace. Do not download or copy these folders.
Choose openreading-cowork for Cowork, openreading-chatgpt for ChatGPT Work, or openreading for the matching code client.
This unsigned Apple Silicon preview contains the parser-free connector. Start Core separately.
Other platforms, native walkthroughs and clean-machine acceptance remain pending.
See https://github.com/openreading-ai/openreading-agent-tools for setup and release status.
